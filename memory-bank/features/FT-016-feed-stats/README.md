# FT-016: Feed Stats

## Problem

Нет ощущения "пульса" системы. Непонятно: сколько постов пришло сегодня? Все ли коллекторы работают? Система живая или застряла?

## Outcome

Под заголовком Feed — строка с ключевыми показателями: "14 постов сегодня · 3 источника · последнее обновление 12 минут назад".

## Scope

- Счётчик постов за выбранный период (берётся из уже загруженных items)
- Количество уникальных источников в текущей выборке
- Timestamp последнего поста в ленте ("последнее обновление X минут назад")
- Только фронтенд — считается из данных в памяти, без нового API

## Notes

- Статистика должна обновляться при смене date-пресета (FT-014)
- Если 0 постов за сегодня — это сигнал, что коллекторы не работают
