# FT-014: Date Quick Filters

## Problem

Feed view показывает месяцы контента без возможности быстро увидеть только сегодняшнее. Ежедневный workflow — "открыл, прочитал новое за сегодня" — невозможен без ручного ввода дат.

## Outcome

Пользователь открывает Feed → жмёт "Сегодня" → видит только посты за последние 24 часа, отранжированные по score.

## Scope

- Кнопки-пресеты в Feed view: **Сегодня** / **Вчера** / **7 дней** / **Всё**
- Активный пресет сохраняется в URL (query param `period=today`) для закладки
- Пресеты транслируются в `from`/`to` параметры `GET /v1/feed` (API уже поддерживает)
- Только фронтенд — бэкенд не меняется

## Notes

- API уже принимает `from` и `to` — это чистый UI-спринт
- "Сегодня" = от начала текущего дня (00:00 local time) до now
